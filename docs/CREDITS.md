# Credits

Every asset we ship must be CC0, CC-BY (3.0 / 4.0), or OFL (fonts). This file is the legal record: one entry per pack, with
the exact licence and source URL checked on the pack's own page on 2026-10-28.

**Attribution rule.** Packs in the CC-BY table REQUIRE a visible credit in the game's Credits screen (and the page footer) naming
the author and linking the source. CC0 packs need nothing but are credited here and in-game as a courtesy. Where a page lists
several licences (for example `CC-BY 3.0 + CC-BY-SA 3.0`), we elect the **CC-BY** option only; we never rely on the SA, GPL or
OGA-BY terms.

"Used for" is the planned role; packs not yet wired into the manifest are still listed so the record is complete. Delete the entry
of any pack that is dropped before release.
